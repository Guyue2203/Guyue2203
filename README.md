## 关于我

我在中国人民大学化学与生命资源学院读书。专业属于化学，但好奇心从不太服从学科边界。

我喜欢把遇到的问题做成真正能用的东西：整理化学数据、改进校园信息检索、搭建个人服务，也为照片寻找一种更接近记忆的呈现方式。代码于我不是终点，而是一种把想法变成现实的工具。

屏幕之外，我也写作、摄影，喜欢书、音乐与自然。我持续维护自己的个人网站和博客，把它们当作数字世界里的一间小屋。
